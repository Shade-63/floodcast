# FLOODCAST — Provisional Predictions CSV Export Schema

> **Notice:** The BASINSHIFT challenge specification provides an illustrative JSON output contract but does not freeze a standardized CSV submission schema. This CSV schema represents the provisional production export specification for FLOODCAST and will remain provisional until the official evaluation benchmark freezes its tabular submission format.

---

## 1. File Specification

- **File Name:** `predictions.csv`
- **Encoding:** `UTF-8`
- **Delimiter:** Comma (`,`)
- **Header:** Required on line 1.
- **Granularity:** Exactly one row per **river basin** (`catchment_id`) and **forecast origin date** (`forecast_origin`).

---

| Column Name | Data Type | Units / Range | Canonical Definition |

## 3. Physical Invariants & Calibration Semantics

1. **Non-Negativity:** River flow cannot be negative ($q \ge 0.0\text{ mm/day}$). Predictions are mathematically clipped at zero during exponential residual inversion.
2. **Probability Hierarchy:** At every horizon $h \in \{+1\text{d}, +3\text{d}, +7\text{d}\}$, the condition $P(P99) \le P(P95)$ is strictly satisfied. Any raw logit inversion that violates monotonicity is projected to the isotonic boundary.
3. **Canonical Discharge Unit:** All discharge values are expressed in area-normalized millimetres per day ($\text{mm/day}$). To convert to volumetric flow rate ($Q$ in $\text{m}^3/\text{s}$):
   $$Q = \frac{q \cdot A}{86.4}$$
   where $A$ is the basin area in $\text{km}^2$ from the CAMELS-BR basin characteristics catalog.
4. **No Synthetic Values:** Only actual inference runs generated by the trained `BasinShiftMultiTask` model on validated historical observation windows are exported. Missing or uncomputed catchments are never populated with fabricated placeholders.
5. **No Formal Discharge Prediction Intervals:** This model produces point regression forecasts and calibrated threshold exceedance probabilities. No parametric prediction intervals (e.g., 90% confidence bands) are included in this export.

---

## 4. Model and Dataset Provenance

- **Model Architecture:** `BasinShiftMultiTask` (2-Layer LSTM temporal encoder with 128 hidden units + 2-layer MLP static catchment encoder + shared feature fusion).
- **Dataset:** CAMELS-BR v1.2 (Hydrometeorological time series across 897 Brazilian river basins).
- **Dynamic Input Channels:** Streamflow ($\text{mm/day}$), Precipitation ($\text{mm/day}$), Mean Surface Temperature ($^\circ\text{C}$).
- **Static Attributes:** Exactly 29 geological, soil, topography, land cover, and human regulation characteristics.
- **Evaluation Group:** Out-of-sample performance is benchmarked on 115 threshold-eligible test basins withheld in 3 disjoint geographic clusters.

---

## 5. Known Operational Limitations

1. **+7 Day P99 Uncertainty:** The calibrated model achieves an AUPRC of 0.066 and Recall of 10.4% for P99 extreme event detection at the 7-day horizon on withheld test catchments. It is an experimental indicator and should not be used as a standalone emergency trigger.
2. **Historical Dependency:** Forecasts require exactly 30 continuous days of historical observations prior to $t_0$. Gauges with intermittent telemetry or missing records cannot generate valid forecasts without prior imputation.
3. **Statistical Thresholds vs Civil Defense Levels:** P95 and P99 represent historical statistical distribution quantiles, not certified local civil defense flood stages or levee breach heights.
