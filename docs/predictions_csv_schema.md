# FLOODCAST — Predictions CSV Export Specification

**Format:** UTF-8 Encoded Comma-Separated Values (CSV)  
**Schema Status:** Provisional (Adaptable to Official Organizer Ingestion Pipeline)  
**Machine-Readable Schema:** [`docs/predictions.schema.json`](file:///Users/vrushabhdadabaravkar/floodcast/docs/predictions.schema.json)  
**Authoritative Units:** Discharge in millimeters per day ($\text{mm}/\text{day}$); Probabilities in range $[0.0, 1.0]$.  

---

## 1. Column Definitions & Header Order

Every row represents one forecast origin for a specific river basin:

| Column Order | Column Header | Data Type | Physical Unit | Description / Constraints |
| :---: | :--- | :--- | :--- | :--- |
| 1 | `catchment_id` | String (8 digits) | N/A | CAMELS-BR 8-digit station code (e.g., `10500000`). |
| 2 | `forecast_origin` | ISO Date | YYYY-MM-DD | Terminal date of the 30-day antecedent observation window. |
| 3 | `target_date_1d` | ISO Date | YYYY-MM-DD | Forecast date for +1 day horizon (`forecast_origin + 1 day`). |
| 4 | `predicted_discharge_1d` | Float | mm/day | Model predicted daily specific runoff at +1d ($Q \ge 0$). |
| 5 | `target_date_3d` | ISO Date | YYYY-MM-DD | Forecast date for +3 day horizon (`forecast_origin + 3 days`). |
| 6 | `predicted_discharge_3d` | Float | mm/day | Model predicted daily specific runoff at +3d ($Q \ge 0$). |
| 7 | `target_date_7d` | ISO Date | YYYY-MM-DD | Forecast date for +7 day horizon (`forecast_origin + 7 days`). |
| 8 | `predicted_discharge_7d` | Float | mm/day | Model predicted daily specific runoff at +7d ($Q \ge 0$). |
| 9 | `p95_probability_1d` | Float | $[0.0, 1.0]$ | Calibrated exceedance probability of catchment P95 flow at +1d. |
| 10 | `p99_probability_1d` | Float | $[0.0, 1.0]$ | Calibrated exceedance probability of catchment P99 flow at +1d ($P \le P_{\text{P95}}$). |
| 11 | `p95_probability_3d` | Float | $[0.0, 1.0]$ | Calibrated exceedance probability of catchment P95 flow at +3d. |
| 12 | `p99_probability_3d` | Float | $[0.0, 1.0]$ | Calibrated exceedance probability of catchment P99 flow at +3d ($P \le P_{\text{P95}}$). |
| 13 | `p95_probability_7d` | Float | $[0.0, 1.0]$ | Calibrated exceedance probability of catchment P95 flow at +7d. |
| 14 | `p99_probability_7d` | Float | $[0.0, 1.0]$ | Calibrated exceedance probability of catchment P99 flow at +7d ($P \le P_{\text{P95}}$). |

## 3. Strict Validation & Rejection Invariants

Any file submitted or parsed must adhere to the following rules:
1. **No Negative Values:** Any `predicted_discharge < 0` triggers immediate hard rejection.
2. **Physical Hierarchy:** $P(\text{P99}) \le P(\text{P95})$ at all lead times.
3. **No Missing Cells:** All 14 fields must be populated with finite numbers and valid ISO dates.
4. **No Synthesized / Fabricated Rows:** Every row must be generated by a verified forward pass through the authoritative PyTorch model engine.
